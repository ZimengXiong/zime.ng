   ### "Differential Equations", lol

   The differential acts as an averaging mechanism for rotational
   velocities:

       ω_diff = (ω₁ + ω₂)/2

   where ω₁ and ω₂ are the input rotational velocities. Thus, we need to
   split this section into two parts, by first calculating A₁,₁ and A₁,₂

   ## Section III
   --------------

   We notice a heuristic here,

   

   We notice A₁:A₂ = A₃:A₄, so we can use the same transformation function
   for both sections.

   Section III Summary: A₄ = A₂(A₃) = -A₃ × 3

   Thus, we just plug A3 back into our A1->A2 function, and we solve the
   entire system with:

   .-----------------------------------------------------------------------
   | ```python
   | def A1_A2(a1):
   |     """
   |     Transform A1 → A2 through Section I
   |     """
   |     return A2(B1(B_1_1(a1), B_1_2(a1)))
   |
   | def A2_A3(a2):
   |     """
   |     Transform A2 → A3 through Section II
   |     """
   |     a2_1 = A_2_1(a2)
   |     b2 = B2(B_2_1(a2_1), B_2_2(a2_1))
   |     b3_1 = B3_1(b2)
   |     b3_2 = B3_2(a2)
   |     b3 = B3(b3_1, b3_2)
   |     return A3(b3)
   |
   | def A3_A4(a3):
   |     """
   |     Transform A3 → A4 through Section III (same as Section I)
   |     """
   |     return A1_A2(a3)
   |
   | def solveSystem(a1):
   |     """
   |     Complete system solution: A1 → A2 → A3 → A4
   |     """
   |     return A3_A4(A2_A3(A1_A2(a1)))
   |
   | print(solveSystem(-17198))
   '-----------------------------------------------------------------------


   ## Complete System Solution
   ---------------------------

   The complete system can be represented as a series of transformations:

   A₂ = f₁(A₁) = -A₁ × 3 A₃ = f₂(A₂) = -(B₃,₁(A₂) + B₃,₂(A₂))/2 A₄ = f₃(A₃)
   = -A₃ × 3

   Final System Equation: A₄ = f₃(f₂(f₁(A₁)))

   Where the overall transformation is: A₄ = A₁ × 9 × (B₃,₁(A₁ × 3) +
   B₃,₂(A₁ × 3))/2

   ## Complete System Analysis
   ---------------------------

   ### Mathematical Summary

   Key Equations:

   1. Differential Averaging: ω_diff = (ω₁ + ω₂)/2

   2. Section I Transformation (A₁ → A₂): A₂ = -A₁ × 24/8 × 16/8 × 1/2 =
      -A₁ × 3

   3. Section II Transformation (A₂ → A₃): A₃ = -(B₃,₁(A₂) + B₃,₂(A₂))/2

   4. Section III Transformation (A₃ → A₄): A₄ = -A₃ × 3

   Complete System Solution: A₄ = A₁ × 9 × (B₃,₁(A₁ × 3) + B₃,₂(A₁ × 3))/2
